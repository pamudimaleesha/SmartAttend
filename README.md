# 📚 SmartAttend
## Smart QR Code Attendance Management System

SmartAttend is a modern QR Code based attendance management system designed to simplify classroom attendance tracking.  
The system allows students to mark attendance by scanning QR codes while lecturers can generate QR codes and monitor attendance records.

---

## 🚀 Features

### 👨‍🎓 Student Features
- Student login and authentication
- Scan attendance QR codes
- GPS location verification
- View attendance history
- Student dashboard

### 👨‍🏫 Lecturer Features
- Lecturer login
- Generate attendance QR codes
- View student attendance records
- Manage classroom attendance

## ⚙️ Installation & Setup

### Clone Repository
git clone https://github.com/pamudimaleesha

---

## Frontend Setup

Go to client folder:cd client


Install dependencies:npm install


Run React application:npm run dev

---

## Backend Setup

Go to server folder:cd server

Install dependencies:npm install


Start server:npm start

---

## 🗄️ Database Setup

1. Open MySQL
2. Create database:smartattend

3. Import database SQL file
4. Update database credentials in `.env`

:DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=smartattend
